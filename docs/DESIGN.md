# 기획서 v0.2 — 인형뽑기 고수인 내가 최고 랭크 사장이 되어보려고 합니다

> v0.2: 영업 방식(하루 단위 + 짧은 영업), 시뮬레이션 구조, 경제 모델, 구매·확장 시스템을 확정/추가했다.
> **표시한 수치는 초안**이며 밸런스 단계에서 `js/config.js` / `js/data.js`로 옮겨 조정한다.

## 한 줄 소개
창동 아레나 상권에 인형뽑기 가게를 연 신인 사장 **플레이어(주인공)**가, 가게를 키우고 업그레이드해서 **전국 인형뽑기 가게 랭킹 1위**에 오르는 타이쿤 게임.

## 화면 디자인
- 테마: 흰색 톤 배경 + 푸른 계열 버튼, 8비트 도트풍. 폰트는 Galmuri. 세부 규칙은 `docs/UI_GUIDE.md`.
- **메인 화면**: 전체 도트 풍경(창동 아레나 모티브) 위에 크기가 다른 제목, 하단 [시작하기(이어하기)]·[게임 설명]·[크레딧], 우상단 설정 톱니.
- 흐름: 메인 → (처음이면) 이름 입력 → 프롤로그 컷신(오락실 → 핸드폰 뉴스 → 공사장 → 인파 → 가게 이름 짓기) → 가게 화면. 저장이 있으면 이어하기로 바로 가게 화면.
- 소리: 배경음악 한 곡 반복 + 합성 효과음, 설정에서 슬라이더·음소거.

## 세계관과 톤
- 약간의 픽션이 가미된 일상. 정석적인 타이쿤 게임 느낌(성장과 수집, 숫자가 쑥쑥 오르는 재미).
- 배경은 서울 창동 아레나 상권. 지명만 배경으로 쓰고, 가게·이웃 상점·라이벌은 전부 가상.
- 재화는 현실적인 돈(원화). 별도 재화 이름 없음.

## 주인공
- **주인공 = 플레이어**: 게임 시작 때 이름을 입력하고(저장되어 대사와 화면에 사용), 컷신 안에서 가게 이름도 직접 짓는다.
- 설정: 평소 인형뽑기를 아주 좋아하는 **고수**. 고수 설정은 **스토리 설정일 뿐 시스템(능력치·보너스)과는 무관**하다.
- 조력자는 없다. 단골·라이벌 캐릭터도 두지 않는다. 손님은 유형별 일반 NPC, 라이벌은 이름만 있는 순위표 항목이다.

## 핵심 루프 (확정)
**하루 단위**로 돈다. 게임의 하루 = 현실의 하루.
1. **준비**(턴): 오늘 진열할 인형 배정, 기계별 설정(한 판 가격, 집게 힘), 발주·구매·확장 결정.
2. **영업**(짧은 실시간): 영업 시간(10:00~22:00)을 **현실 약 2분**에 압축해 보여 준다. **배속(2×/4×/8×)과 영업 건너뛰기** 지원. 플레이어는 틈틈이 개입한다(고장 수리, 인형 보충, 클레임 응대).
3. **정산**: 매출, 비용, 손익, 만족도·평판·인기도 변화, 오늘의 사건 요약.
4. 반복하며 **가게 랭크**(5랭크 → 1랭크)를 올리고, 1랭크가 되면 **전국 순위**를 올린다. (전국 1위 = 목표이자 엔딩, 엔딩 후에도 계속 운영 가능)

목표 템포: 하루 약 3분(준비 + 영업 + 정산) × 100~200일 ≈ 5~10시간.

## 시뮬레이션 구조 ("심시티" 방식: 전부 계산하되 일부만 그린다)
계산 층과 표현 층을 분리한다. **돈·시간·인원은 현실 그대로** 계산하고(손님 수를 줄이거나 지출을 부풀리지 않는다), 화면에는 일부만 보여 준다.

- **틱**: 가상 시계 1분 = 1틱. 영업 12시간 = 720틱 → 2분 영업이면 초당 6틱. 배속은 틱 간격만 줄인다(계산 결과는 동일, 시드 고정으로 재현 가능).
- **계산 층(모든 손님)**: 매 틱 유동인구(시간대 곡선 × 요일 × 이벤트/공연 × 날씨 × 위치 × 평판)에 따라 방문객이 도착 → 손님 유형·예산·선호 태그·인내심을 뽑음 → 기계/인형 선택 → 여러 판 진행(성공 확률 = 집게 힘·인형 난이도) → 만족/불만 → 재방문 의사. 하루 300~500명 수준이라 연산은 가볍다.
- **표현 층(대표 손님)**: 화면에는 대표 손님 6~10명만 스프라이트로 움직인다. 나머지는 줄·군중 실루엣과 집계 숫자(방문객, 판 수, 매출)로 보여 준다. 선정 규칙: **사건 우선**(대박 경품, 고장, 클레임, 품절, 고수 등장) → 나머지는 무작위 샘플.
- **플레이어 개입 지점**은 계산에서 뽑힌 사건에서만 나온다(전 손님을 직접 다루지 않는다).
- **상태가 쌓이는 값**: 기계 가동·고장 확률, 재고, 평판, 인기도, 유행 태그, 일별 기록(그래프용).

## 경제 모델 (현실 반영)
- **기본 수식**: 판당 순수익 = 한 판 가격 − (뽑힐 확률 × 인형 원가). 집게 힘(확률)을 올리면 만족도·재방문이 오르고 원가가 늘며, 내리면 돈은 남지만 평판이 떨어진다. → 타이쿤의 균형점.
- **환수율**(매출 대비 경품 원가) 목표 약 35~45%.
- **시간 단위**: 월 고정비(임대료 등)는 **일할(÷30)** 로 매일 정산한다. 하루 정산 = 하루 손익.
- **비용 항목**: 인형 원가(발주), 임대료, 전기·수리비, 인건비(직원 고용 후), 창고·확장 유지비.
- **압축하는 것은 연출 시간뿐**이다. 진행이 느리면 배속·건너뛰기로 해결한다.

### 초안 수치 (밸런스 단계에서 조정)
| 항목 | 초안 |
|---|---|
| 시작 자금 | 3,000,000원 |
| 한 판 가격 | 기본 1,000원 (설정 500~2,000) |
| 인형 원가 | 소형 800~1,500 / 중형 3,000 / 대형 8,000+ (희귀·한정은 가산) |
| 기계 1대 구입가 | 약 1,200,000원 (시작 시 2대 보유 가정) |
| 월 임대료(소형 점포) | 약 900,000원 → 하루 30,000원 |
| 기계당 하루 전기 | 약 2,000원, 가동일수에 따라 고장 확률 증가 |
| 하루 방문객(초반) | 약 100~150명, 방문당 평균 약 2판 |
| 초반 하루 순익 감 | 매출 ~24만 − 인형 원가 ~10만 − 임대 3만 − 전기·수리 ~1만 = **약 10만 원/일** (기계 1대 추가에 약 12일) |

## 구매와 확장 (돈의 용도)
정산/준비 단계에서 돈으로 아래를 할 수 있다. 모든 구매는 확인 단계를 거치고, 금액·효과를 미리 보여 준다.

1. **기계 추가 구입**: 기계는 **여러 종류**(아래 표). 점포 칸(슬롯) 수는 가게 크기가 정하고 기계마다 차지하는 칸이 다르다. 기계가 늘수록 동시에 받을 수 있는 손님·진열 다양성이 늘지만 전기·고장 관리 부담도 는다. 기계는 가동일수가 쌓일수록 고장 확률이 오르고, 중고로 팔 수 있다(구입가의 40%).
2. **인형 발주**: 도매 카탈로그에서 인형을 종류·수량으로 주문. 규칙(초안):
   - **리드타임** 당일 주문 → 다음 날 아침 입고, **묶음 할인**(수량이 많을수록 단가 ↓),
   - 유행 태그에 따라 **시세 변동**(유행 인형은 비싸고 품절 위험),
   - 재고가 모자라면 기계에 못 채워 매출이 줄고, 많이 쌓아 두면 창고 용량을 차지한다.
3. **창고 확장**: 보관 가능한 인형 수 상한(용량)을 단계적으로 늘린다. 용량이 커질수록 한 번에 대량 발주(할인)와 유행 대비 비축이 가능하지만 유지비가 든다.
4. **가게 확장**: 점포 단계를 올린다(더 큰 점포로 이전/증축). **슬롯 수 증가·유동인구 노출 증가**와 함께 **임대료·유지비 증가**. 가게 랭크 상승 조건과 연결된다.
5. (이후) 인테리어, 직원 고용(영업 중 자동 대응), 시설(휴게 공간, 사진 부스) 업그레이드.

## 가게 랭크와 인기도 랭킹
- **가게 랭크는 5랭크부터 1랭크까지**다. 막 문을 연 가게는 모두 **5랭크**(동네 가게)에서 시작하고, 4랭크(상권 대표) → 3랭크(도시 명소) → 2랭크(지역 강자) → **1랭크(전국구)** 로 오른다. 랭크마다 새 인형·새 기계, 가게 확장 한도가 열린다.
- **랭크는 가게의 수익과 인기도로 정해진다**: 다음 랭크로 오르려면 **인기도**와 **최근 평균 일매출**을 모두 채워야 한다(초안: 인기도 150/350/700/1,400, 일매출 10만/20만/35만/60만 원).
- **1랭크부터는 자세한 전국 순위가 표시된다**(5~2랭크에서는 랭크 구간만 보인다). 라이벌 가게 약 300곳과 인기도 점수로 겨루며, **최종 목표는 전국 1등**이다. **1위 달성 = 엔딩**(1회 연출, 이후 계속 운영 가능).
- 라이벌 점수는 시즌 변동이 있고 시간이 지날수록 조금씩 성장한다(1위 약 7,000점 기준 초안).
- **스토리 소개**: 랭크의 존재는 개업 첫날(1일차 영업을 시작할 때) **"인형뽑기 애호가 클럽 회장"**(이상한 양복 입은 사내)이 찾아와 알려 준다. 이를 계기로 주인공은 "까짓거 전국 1등에 도전하겠다"는 목표를 갖는다. 컷신은 구현됨(영업 화면이 생기면 1일차 영업 시작 시점으로 옮긴다).
- 인기도 점수(안): 매출, 손님 만족도, 평판(클레임 처리), 시설 수준, 인형 라인업(유행 대응), 이벤트 성과.
- 라이벌은 캐릭터 없이 가상 가게 이름과 점수만 가진다. 시즌마다 순위가 변동한다.

## 기계와 인형
- **기계는 여러 종류**이고, 종류마다 넣을 수 있는 인형 크기·집기 쉬움·한 판 시간·가격대·손님 인기가 다르다. 같은 기계도 설정(한 판 가격, 집게 힘 1~5단계)과 진열 인형으로 달라진다.

| 기계 | 특징 | 넣을 수 있는 인형 | 초안 구입가 |
|---|---|---|---|
| 소형 뽑기 기계 | 작고 싸다. 한 판 짧음(약 55초), 학생·구경 손님이 선호 | **소형 인형 전용**. 중형은 겨우 들어가며(칸 3개 차지, 잘 안 집힘), **대형 인형은 넣을 수 없다** | 700,000 |
| 일반 뽑기 기계 | 가장 무난한 기본 기계 | 소형·중형·대형 | 1,200,000 |
| 대형 뽑기 기계 | 점포 칸 2개 차지, 눈에 띈다. 연인 손님 선호, 전기·수리비 높음 | 대형 인형이 가장 잘 어울림(소형은 휑해 보임) | 2,800,000 |
| 타이머 뽑기 기계 | **정확한 시간(예: 10.00초)에 버튼을 눌러야** 경품을 준다. 보통 **엄청 큰 인형(초대형)** 을 넣어 이목을 끈다(가게 앞 눈길 효과: 방문객 소폭 증가). 집게 힘 대신 **허용 오차**(±0.04~0.005초)로 난이도를 정하고, 버튼 감각이 좋은 **고수 손님이 특히 잘 맞춘다** | 대형·**초대형**만 | 1,800,000 (2랭크부터) |
| (추가 예정) | 경품 박스형, 이벤트 한정 기계 등 | | |

- 기계 데이터는 `DATA.MACHINES`(종류 추가는 이 표에 항목만 늘리면 된다). 대형 기계는 2랭크, 타이머 기계는 2랭크부터 구입할 수 있다.
- 인형 크기는 **소형(S) / 중형(M) / 대형(L) / 초대형(XL)**. 초대형 인형은 원가가 매우 높아(약 28,000~42,000원) 타이머 기계 전용이다.
- **인형은 전부 오리지널**. 인형마다 **속성 태그**를 가진다(손님 선호와 맞물리는 시스템의 핵심).
  - 태그 후보(초안, 나중에 정리): 크기(소/중/대), 계열(동물·음식·우주·탈것 등), 등급(일반/희귀/한정), 분위기(귀여움/코믹/시크), 계절·행사, 유행 여부, 가격대.
  - 유행은 주기적으로 바뀌며 유행 태그를 가진 인형은 수요·시세가 오른다.

## 손님
- **유형(초안, 나중에 정리)**: 가족, 연인, 인형뽑기 고수, 구경꾼, 학생, 외국인 관광객 등. 유형마다 예산·인내심·선호 태그·판당 지출 분포가 다르다.
- 상태 머신: 입장 → 기계/인형 선택 → 시도(여러 판) → 만족/불만 → (재시도/퇴장).
- 손님 선호 태그와 진열 인형 태그가 맞을수록 방문·판 수가 늘고 만족도가 오른다. 만족도는 평판과 인기도에 반영된다.

## 이벤트
- 아레나 공연일: 유동인구 폭증 + 한정 인형 수요(달력에서 미리 확인 → 발주·재고 준비).
- 기계 고장, 클레임 손님, 인형 품절, 라이벌 가게 이벤트.
- 선택 요소: 주인공이 직접 뽑아 보는 미니게임(터치 조작).

## 엔딩
- **전국 1위 엔딩**: 1랭크에서 전국 인기도 순위 1위 달성.
- **폐업(게임 오버)**: 돈이 다 떨어지면 폐업.
- **엔딩 이후에도 이어서 계속 운영할 수 있다**.

## 기술 방향
- 순수 JS + HTML5 Canvas, 빌드 도구 없음. 논리 해상도 960×576, 도트풍.
- **시뮬레이션 코어는 화면과 분리**(별도 파일, DOM·Canvas 무관): 시드 기반 난수, 하루를 한 번에 돌려 결과를 돌려주는 함수를 만들어 **콘솔/테스트로 밸런스를 먼저 검증**한다. 영업 화면은 그 결과(틱별 이벤트 로그)를 재생하는 방식으로 연결한다.
- 수치(가격, 확률, 성장 곡선)는 `js/config.js`, 데이터(인형, 손님, 이벤트, 라이벌)는 `js/data.js`.
- localStorage 저장. 터치 우선 UI(큰 버튼, 호버 의존 금지).

## 시뮬레이션 코어 (구현됨)
- 파일: `js/sim.js`(순수 계산), 수치 `CFG.SIM`, 데이터 `DATA.DOLLS` / `DATA.MACHINES` / `DATA.CUSTOMERS`.
- 검증 도구: `node tools/simrun.js [일수] [시드] [--daily] [--detail] [--nobuy] [--idle]` — 화면 없이 며칠을 돌려 방문객·판 수·매출·환수율·이탈 사유·평판을 확인한다. 같은 시드는 같은 결과(결정적).
- 현재 초안 수치로 검증한 결과(자동 운영 봇): 하루 방문 약 100~180명, 방문당 약 1.5~2판, 환수율 약 45~50%, 하루 손익 약 9~12만 원, 4랭크 약 50일, 3랭크 약 75일, 2랭크 약 125일. **1랭크(전국 순위 표시)는 200일 안에 못 간다**(후반 성장 곡선을 더 다듬어야 함).
- 알려진 밸런스 숙제: 후반 평판이 100에 포화, 손님이 "마음에 드는 인형 없음"으로 돌아가는 비율이 20~30%(진열·태그 설계로 조절), 타이머 기계의 환수율이 낮음(약 25%), 소형 기계의 중형 인형 환수율이 높음.
