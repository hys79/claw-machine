# 기획서 초안 v0.1 — 인형뽑기 가게 타이쿤 (가제)

## 한 줄 소개
창동 아레나 상권에 인형뽑기 가게를 연 신인 사장 **주인공(이름 미정)**이, 가게를 키우고 업그레이드해서 **세계 인형뽑기 가게 인기도 랭킹 1위**에 오르는 타이쿤 게임.

## 세계관과 톤
- 약간의 픽션이 가미된 일상. 정석적인 타이쿤 게임 느낌(성장과 수집, 숫자가 쑥쑥 오르는 재미).
- 배경은 서울 창동 아레나 상권. 지명만 배경으로 쓰고, 가게·이웃 상점·라이벌은 전부 가상.
- 재화는 현실적인 돈(원화). 별도 재화 이름 없음.

## 주인공
- **주인공(이름 미정)**: 인형뽑기를 좋아하는 신인 사장. 창동 아레나 상권에서 인형뽑기 가게를 창업한다.
- 조력자·단골·라이벌은 가상 인물로 새로 만든다(후속 논의).

## 핵심 루프
1. **준비**: 오늘 들여놓을 인형을 고르고, 기계 배치와 난이도(집게 힘, 확률)를 설정한다.
2. **영업**: 손님이 오고 기계를 이용한다. 플레이어는 틈틈이 개입한다(고장 수리, 인형 보충, 상품 교체, 클레임 응대).
3. **정산**: 매출, 비용, 만족도, 인기도 변화를 확인한다.
4. **확장**: 기계, 인형 라인업, 인테리어, 직원, 가게 시설을 업그레이드한다.
5. 반복하며 **가게 랭크**를 올리고, **인기도 랭킹**에서 순위를 끌어올린다.

## 시스템

### 돈과 가게 랭크
- 매출에서 임대료, 인형 매입비, 전기·수리비, 인건비를 제한 순이익으로 투자한다.
- **가게 랭크**: 업그레이드 투자가 쌓이면 오르는 성장 단계. 랭크마다 새 기계, 새 인형, 새 상권(위치 확장)이 열린다.
- 랭크 단계(안): 동네 가게 → 상권 대표 → 도시 명소 → 전국구 → 세계구.

### 인기도 랭킹
- 가상의 라이벌 가게들과 겨루는 랭킹 시스템. **1위 달성 = 목표이자 엔딩.**
- 인기도 점수 구성(안): 매출, 손님 만족도, 평판(클레임 처리), 시설 수준, 인형 라인업(유행 대응), 이벤트 성과.
- 라이벌 가게는 가상 이름과 특징을 가진 NPC로, 시즌마다 순위가 변동한다.

### 기계와 인형
- 기계 종류(안): 기본 집게 / 대형 / 미니 / 뽑기 난이도 특화 / 프리미엄(고급 경품).
- **집게 힘과 확률 설정**: 너무 세게 하면 손해, 너무 약하면 평판 하락. 타이쿤의 핵심 균형.
- 인형은 전부 오리지널 캐릭터. 등급(일반/희귀/한정)과 유행 주기가 있다.
- 재고 관리: 유행하는 인형을 읽고 발주한다. 신상 대박·품절 이벤트.

### 손님
- 유형(안): 가족, 연인, 인형뽑기 고수, 구경꾼, 단골.
- 상태 머신: 입장 → 기계 선택 → 시도 → 만족/불만 → (재시도/퇴장).
- 만족도가 평판과 인기도에 반영된다.

### 이벤트
- 아레나 공연일: 손님 폭증 + 한정 인형 수요.
- 기계 고장, 클레임 손님, 인형 품절, 라이벌 가게 이벤트.
- 선택 요소: 주인공이 직접 뽑아 보는 미니게임(터치 조작).

## 엔딩
- **1위 엔딩**: 세계 인기도 랭킹 1위 달성.
- (후속 논의) 도전 중 실패/폐업 조건 유무, 1위 이후 샌드박스 모드 유무.

## 기술 방향
- 순수 JS + HTML5 Canvas, 빌드 도구 없음. 논리 해상도 960×576, 도트풍.
- 수치(가격, 확률, 성장 곡선)는 `js/config.js`, 데이터(기계, 인형, 손님, 이벤트, 라이벌)는 `js/data.js`.
- localStorage 저장. 터치 우선 UI(큰 버튼, 호버 의존 금지).
