# 기획서 초안 v0.1

## 한 줄 소개
무기력한 근령이를 베리 코치와 함께 키워 **증바람 프로리그 우승**까지 데려가는 육성 시뮬레이션.

## 핵심 루프
1. **주간 계획**(월~일, 하루 2칸: 낮/밤)에 행동을 배치한다.
2. **경기일**에 팀파이트(자동 전투 + 개입)를 치른다.
3. 결과로 능력치·재화·팬·멘탈이 변하고, 이벤트가 발생한다.
4. 시즌 끝에 순위 정산, 다음 시즌으로. 3시즌 안에 월드 파이널 우승이 목표.

## 육성 능력치 (근령이)
| 능력치 | 의미 |
|---|---|
| 손(피지컬) | 스킬샷 적중, 회피 |
| 판단력 | 교전 진입·후퇴 타이밍 |
| 팀파이트 | 한타 포지셔닝, 궁극기 활용 |
| 챔프 이해도 | 챔피언 풀 폭 |
| 멘탈 | 연패·역전패 후 회복, 타일트 저항 |
| 체력 | 장시간 경기 후반 집중력. **운동을 싫어해서 잘 안 오른다**(주요 개그) |
| 귀찮음(0~100) | 높을수록 행동 효율 ↓, 지각·불참 위험 ↑ |

## 행동(주간 계획)
솔로 랭크 / 챔프 연습 / 팀 스크림 / 영상 복기 / 체력 훈련(싫어함) / 휴식 / 낮잠 / 방송·팬서비스 / 외출(친구)
- **"5분만 더"**: 매 행동 후 근령이가 요청. 받아주면 효율↑ 귀찮음↓ 그러나 다음 일정 지각 위험.

## 경기 (증바람식 팀파이트)
- 5:5 무작위 챔피언, 일직선 한 라인 맵(오리지널 "눈 덮인 다리").
- **밴픽 대신 리롤/교환**: 시작 시 랜덤 배정, 리롤 토큰으로 바꾼다.
- 팀파이트 매니저식: 경기 전 **전술 3택**(진입/포킹/수비), 경기 중 **개입 카드** 3장(핑, 스킬 지시, 후퇴 명령).
- 근령이 능력치가 해당 챔피언 숙련도와 결합해 한타 결과 결정. 나머지 4명은 AI 팀원(가상 이름).
- 결과: 승/패 + MVP 지표 + 하이라이트 컷(도트 연출).

## 팀과 팬
- 팀원 4명은 가상 인물, 호감도와 시너지 보너스.
- 팬 수 → 후원금 → 장비/훈련 시설 업그레이드(꿈조각).

## 이벤트 (예시)
- 늦잠으로 스크림 불참 → 코치 베리의 한숨.
- 역전패 직후 멘탈 붕괴 → 대사 "방금 그건 억울하게 죽은 거잖아……"
- 베리에게 말도 안 되는 부탁("나 대신 경기 나가줘") → 거절 이벤트.
- 우승 직전 밤, 짧은 감동 이벤트.
