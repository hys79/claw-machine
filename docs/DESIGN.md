# 기획서 초안 v0.1 — 인형뽑기 고수인 내가 최고 랭크 사장이 되어보려고 합니다

## 한 줄 소개
창동 아레나 상권에 인형뽑기 가게를 연 신인 사장 **플레이어(주인공)**가, 가게를 키우고 업그레이드해서 **세계 인형뽑기 가게 인기도 랭킹 1위**에 오르는 타이쿤 게임.

## 화면 디자인
- 테마: 흰색 톤 배경 + 푸른 계열 버튼, 8비트 도트풍. 폰트는 Galmuri.
- **메인 화면**(목업 기준): 위에서부터 게임 제목 배너 / 창동 아레나·인형뽑기 도트 그림 / 하단에 [시작하기(이어하기)]와 [게임 설명] 버튼. 우상단에 설정(톱니바퀴) 아이콘.
- 설정 팝업: 데이터 초기화(두 번 눌러 확인), 폰트 크레딧. 게임 설명 팝업: 게임 소개 4줄.
- 흐름: 메인 → (처음이면) 프롤로그 대사 → 사장 이름 입력 → 가게 화면. 저장이 있으면 이어하기로 바로 가게 화면.

## 세계관과 톤
- 약간의 픽션이 가미된 일상. 정석적인 타이쿤 게임 느낌(성장과 수집, 숫자가 쑥쑥 오르는 재미).
- 배경은 서울 창동 아레나 상권. 지명만 배경으로 쓰고, 가게·이웃 상점·라이벌은 전부 가상.
- 재화는 현실적인 돈(원화). 별도 재화 이름 없음.

## 주인공
- **주인공 = 플레이어**: **스토리 프롤로그 도중**(가게 신청서의 사장 이름 칸)에 플레이어가 직접 이름을 입력한다(저장되어 대사와 화면에 사용).
- 설정: 평소 인형뽑기를 아주 좋아하는 **고수**이고, 창동 아레나 상권에서 가게를 창업하는 데 관심이 있던 신인 사장.
- 고수 설정은 **스토리 설정일 뿐 시스템(능력치·보너스)과는 무관**하다.
- 조력자는 없다. 모든 조작은 플레이어가 직접 한다.
- 단골·라이벌 캐릭터도 두지 않는다. 손님은 유형별 일반 NPC, 라이벌은 이름만 있는 순위표 항목으로만 존재한다.

## 핵심 루프
1. **준비**: 오늘 들여놓을 인형을 고르고, 기계 배치와 난이도(집게 힘, 확률)를 설정한다.
2. **영업**: 손님이 오고 기계를 이용한다. 플레이어는 틈틈이 개입한다(고장 수리, 인형 보충, 상품 교체, 클레임 응대).
3. **정산**: 매출, 비용, 만족도, 인기도 변화를 확인한다.
4. **확장**: 기계, 인형 라인업, 인테리어, 직원, 가게 시설을 업그레이드한다.
5. 반복하며 **가게 랭크**를 올리고, **인기도 랭킹**에서 순위를 끌어올린다.

## 시스템

### 돈과 가게 랭크
- 매출에서 임대료, 인형 매입비, 전기·수리비, 인건비를 제한 순이익으로 투자한다.
- **가게 랭크**: 업그레이드 투자가 쌓이면 오르는 성장 단계. 랭크마다 새 기계, 새 인형, 새 상권(위치 확장)이 열린다.
- 랭크 단계(안): 동네 가게 → 상권 대표 → 도시 명소 → 전국구 → 세계구.

### 인기도 랭킹
- 가상의 라이벌 가게들과 겨루는 랭킹 시스템. **1위 달성 = 목표이자 엔딩.**
- 인기도 점수 구성(안): 매출, 손님 만족도, 평판(클레임 처리), 시설 수준, 인형 라인업(유행 대응), 이벤트 성과.
- 라이벌은 캐릭터 없이 가상 가게 이름과 점수만 가진 순위표 항목이다. 시즌마다 순위가 변동한다.

### 기계와 인형
- 기계 종류(안): 기본 집게 / 대형 / 미니 / 뽑기 난이도 특화 / 프리미엄(고급 경품).
- **집게 힘과 확률 설정**: 너무 세게 하면 손해, 너무 약하면 평판 하락. 타이쿤의 핵심 균형.
- 인형은 전부 오리지널 캐릭터. 등급(일반/희귀/한정)과 유행 주기가 있다.
- 재고 관리: 유행하는 인형을 읽고 발주한다. 신상 대박·품절 이벤트.

### 손님
- 유형(안): 가족, 연인, 인형뽑기 고수, 구경꾼.
- 상태 머신: 입장 → 기계 선택 → 시도 → 만족/불만 → (재시도/퇴장).
- 만족도가 평판과 인기도에 반영된다.

### 이벤트
- 아레나 공연일: 손님 폭증 + 한정 인형 수요.
- 기계 고장, 클레임 손님, 인형 품절, 라이벌 가게 이벤트.
- 선택 요소: 주인공이 직접 뽑아 보는 미니게임(터치 조작).

## 엔딩
- **1위 엔딩**: 세계 인기도 랭킹 1위 달성.
- **폐업(게임 오버)**: 돈이 다 떨어지면 폐업.
- **엔딩 이후에도 이어서 계속 운영할 수 있다**(1위 달성 후에도 플레이 계속, 엔딩 장면은 1회).

## 기술 방향
- 순수 JS + HTML5 Canvas, 빌드 도구 없음. 논리 해상도 960×576, 도트풍.
- 수치(가격, 확률, 성장 곡선)는 `js/config.js`, 데이터(기계, 인형, 손님, 이벤트, 라이벌)는 `js/data.js`.
- localStorage 저장. 터치 우선 UI(큰 버튼, 호버 의존 금지).

## 구현 단계
0. 제목: "인형뽑기 고수인 내가 최고 랭크 사장이 되어보려고 합니다" 확정
1. [x] 문서 정리, 저장소/프로젝트 뼈대 재정비(타이틀, 이름 입력, 임시 가게 화면, 저장)
2. [ ] 시작 화면(이름 입력) + 가게 화면 + 돈/재고/기계 기본 루프(수치만)
3. [ ] 손님 시뮬레이션, 정산 화면
4. [ ] 업그레이드와 가게 랭크
5. [ ] 인기도 랭킹, 라이벌, 엔딩
6. [ ] 이벤트, 미니게임, 도트 연출
7. [ ] 밸런스, 터치 UI 다듬기, 공개 준비
