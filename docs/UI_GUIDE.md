# UI 가이드 — 인형뽑기 고수인 내가 최고 랭크 사장이 되어보려고 합니다

화면·조작 규격 문서. 값이 바뀌면 코드(`js/config.js`, `js/ui.js`)가 기준이다.
색 톤은 **흰색 바탕 + 푸른 포인트**를 유지한다.

## 1. 원칙
1. **8비트 도트 느낌**: 모서리는 전부 직각, 그림자는 흐리지 않고 딱딱한 오프셋, 이미지는 `image-rendering: pixelated`.
2. **테두리 위계**: 가장 바깥 창(panel)만 굵게(5px), 대사창 3px, 버튼·알약·입력칸은 얇게(2~3px). `CFG.BW`.
3. **색은 흰색·푸른 계열만 UI를 지배**한다. 노랑은 돈·강조(타이틀 둘째 줄, 코인)에만, 빨강은 위험(초기화 확인)에만 쓴다. 분홍·보라는 UI에 쓰지 않는다(배경 그림 제외).
4. **군더더기 안내 문구 금지**. 설명은 게임 설명 팝업에 모은다. 호버에만 의존하는 정보 금지(터치 우선).
5. **글자**: 도트 폰트(Galmuri)는 굵게 하지 않는다. 밝은 면 위 글자는 외곽선 없이, 그림·어두운 면 위 글자는 `ink` 외곽선을 쓴다.
6. 사용자가 지정한 UI 문구·수치는 그대로 존중한다(수정 전 파일을 다시 읽는다).
7. 되돌릴 수 없는 동작(데이터 초기화)은 확인 단계를 거친다(버튼을 한 번 더 눌러야 실행).

## 2. 화면·좌표
- 논리 높이 576 고정, 너비는 창 비율에 따라 768~1440. **UI는 가운데 960 영역**에 두고 배경 그림만 양옆으로 넓어진다.
- 화면 모서리에 붙는 것은 설정 톱니(오른쪽 위)뿐이다.

## 3. 팔레트 (`CFG.COLOR`)
| 이름 | 용도 |
|---|---|
| `bg` `#f3f8fc` | 화면 바탕 |
| `white` | 패널·카드 바탕, 어두운 면 위 글자 |
| `ink` `#14324d` | 글자, **모든 테두리·글자 외곽선** |
| `sub` `#5f7a92` | 보조 글자, 비활성 |
| `soft` / `line` / `edge` | 부드러운 칸 바탕 / 구분선 / 비활성 테두리 |
| `blue` 계열 | 주 버튼(`blue`, 오버 `blueHi`, 윗줄 `blueLight`, 아랫줄 `blueDark`), 제목 밑줄, 불릿 |
| `alert` 계열 | 경고·초기화 확인 |
| `yellow` | 돈·강조 |
| `glass` / `glassLine` | HUD 알약·반투명 상자 |
| `scrim` / `shadow` | 팝업 뒤 어두운 막 / 오프셋 그림자 |

## 4. 공통 부품 (`js/ui.js`)
- `UI.button(rect, label, {style, size, onClick, modal, disabled, draw})`: 그리면서 클릭 영역을 등록한다. 마우스를 올리면 1px 뜨고 밝아진다(터치는 호버 없음). 팝업이 열려 있으면 `modal: true`가 아닌 버튼은 눌리지 않는다.

| 스타일 | 모양 | 용도 |
|---|---|---|
| `primary` | 파란 면 + 흰 글자 | 주 행동(시작·확인·닫기) |
| `secondary` | 흰 면 + 진한 글자 | 보조(게임 설명, 돌아가기, 건너뛰기) |
| `soft` | 연한 파랑 + 회색 글자 | 비활성·잠김 |
| `danger` | 빨간 면 | 되돌릴 수 없는 동작의 확인 단계 |

- 설정 톱니처럼 아이콘만 쓰는 버튼은 `bare: true`(상자 없이 흰 도트 + `ink` 테두리).
- `UI.panel`: 굵은 테두리 창(그림자 포함). `UI.glass`: 반투명 어두운 상자. `UI.scrim`: 팝업 뒤 막.
- `UI.title(문구, x, y, 부제)`: 36px 제목 + 파란 밑줄 + 부제.
- `UI.moneyPill`: 소지금 알약(코인 도트 + 숫자). `UI.dialog`: 흰 대사창 + 위에 걸친 파란 이름표 + 깜빡이는 ▼.
- `UI.text(..., outline)`: 외곽선 글자. `UI.wrap`: 폭에 맞춘 줄바꿈.

## 5. 화면별 구성
공통: **왼쪽 위 소지금 알약**(`LAYOUT.moneyPill`), **왼쪽 아래 돌아가기**(`LAYOUT.backBtn`, 보조 스타일).

| 화면 | 구성 |
|---|---|
| 타이틀 | 도트 풍경 위에 크기가 다른 테두리 글자 제목("최고 랭크 사장이"만 크고 노랗게, 나머지는 작게), 하단 [시작하기(이어하기) 파랑][게임 설명 흰색], 오른쪽 위 톱니 아이콘(상자 없음) |
| 프롤로그(컷신) | `js/cutscene.js`가 `DATA.STORY` 대본을 실행: 오락실 → 공사 중인 아레나 → 몰려드는 사람들 → 전구 → 작은 가게 → 타이틀 카드. 장면마다 페이드, 하단 납작한 대사창(나레이션은 이름표 없음, 생각은 "나" 이름표), 글자 한 자씩 출력. 빈 곳 클릭·Enter·Space로 진행(출력 중이면 먼저 전체 표시), 오른쪽 위 [건너뛰기] |
| 이름 입력 | 흰 창 "가게 신청서": 안내 → 입력칸 → [확인]. 왼쪽 아래 [돌아가기] |
| 가게 | 소지금 알약 + 제목 + 정보 카드(구분선 있는 행) + 왼쪽 아래 [타이틀로] |
| 설정 팝업 | 어두운 막 + 흰 창: 제목·가로선·[처음부터 다시](한 번 더 누르면 빨간 확인)·크레딧·[닫기] |
| 게임 설명 팝업 | 같은 틀, 파란 불릿 4줄 + [닫기] |

## 6. 조작
| 입력 | 동작 |
|---|---|
| 클릭 / 터치 | 버튼, 프롤로그 진행 |
| `Esc` | 팝업 닫기 → 이전 화면(타이틀) → (타이틀에서는) 설정 열기 |
| `Enter` / `Space` | 프롤로그 진행, 이름 입력칸에서 Enter는 확인 |

## 7. 새 화면을 만들 때 체크리스트
① 가운데 960 영역 좌표 ② 직각 + 얇은 테두리 + 바깥 창만 굵게 ③ 흰/파랑 중심, 노랑·빨강은 의미 있는 곳에만 ④ 모든 버튼은 `UI.button`으로(터치 크기 확보) ⑤ Esc로 한 단계씩 뒤로 ⑥ 소지금 알약·돌아가기 위치 통일 ⑦ 되돌릴 수 없는 동작은 확인 단계 ⑧ 수치는 `config.js`에.
